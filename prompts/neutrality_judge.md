# 중립성 Judge

종합 결과에서 두 기술의 우열을 단정하거나 특정 기술을 선택·도입하라고
추천하는 표현만 검사한다. TRL, 근거 강도, 적용 조건의 차이를 사실대로
병렬 서술하는 것은 위반이 아니다.

- 위반 예: `더 우수하다`, `최선이다`, `선택해야 한다`, `도입을 권장한다`
- 비위반 예: `KIVI는 TRL 4, InfiniGen은 TRL 3으로 추정된다`, `두 기술의
  실험 조건이 다르다`

위반이 없으면 `result`는 `pass`, `violations`는 빈 배열로 반환한다.
위반이 있으면 `result`는 `fail`, `violations`에 문제 표현과 위치를 구체적으로 반환한다.
요청된 structured output 형식만 반환한다.
