# 이해관계자 Rubric — 설계서 4.3

| 이해관계자 | 수집할 자료 | 판정 |
|---|---|---|
| 경쟁 기술 진영 | 비슷한 문제를 다른 방식으로 해결하는 경쟁 기술의 비교 자료, 비판·인정 | 우호 / 중립 / 비판 |
| 도입 기업·개발자 | 개발자 커뮤니티의 반응, 정확도·코드 복잡성·하드웨어 요구사항 등 채택 장벽과 유용성 | 우호 / 중립 / 비판 |
| 투자·미디어 | 기술 투자자와 IT 전문 매체가 보는 사업성·트렌드·보도 동향 | 우호 / 중립 / 비판 |

직접 반응을 확인하지 못한 그룹은 "근거 없음"으로 기록한다.
찬성·반대는 기술당 각각 최소 2건을 목표로 한다. 한 발췌문을 반복하거나 바꿔 말해
서로 다른 근거로 세지 않는다. 동일 페이지여도 서로 다른 구체적 사실은 별개 근거가 될 수 있다.
반대 근거가 2건 미만이면 Dispatcher가 최대 2회 재검색한다.
상한 도달 후 부족하면 "반대 근거 확보 실패 [추론]"을 기록하며, 실패 표시를 실제 반대 근거로 해석하지 않는다.
