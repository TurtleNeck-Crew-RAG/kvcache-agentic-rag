# 시장성 Rubric — 설계서 4.2

| 항목 | 상 | 중 | 하 |
|---|---|---|---|
| 채택 | 거대 기업 또는 주요 AI 프레임워크가 해당 기술을 공식 도입하거나 언급 | 다른 연구자·오픈소스 개발자의 후속 연구·활용 | 논문 발표에 머물고 후속 관심·활용이 없는 상태 |
| 시장 연결 | 온디바이스 LLM 시장 자료에서 해당 접근을 직접 언급 | 메모리 절감 수요라는 넓은 범주에서만 간접 언급 | 시장 조사 자료에서 언급이 없는 상태 |
| 생태계 | 구현체 최소 2개 이상이며 표준화·업계 로드맵도 존재 | 구현체 1개 | 사용 가능한 구현체 코드 없음 |

각 축은 독립적으로 판정한다. 상의 조건은 모두 충족해야 한다.
검색 결과가 비었다는 사실만으로 하를 확정하지 말고, 상태를 판단할 증거가 부족하면
"근거 없음"으로 기록한다. PR 제안·진행·머지·제품 채택을 구별하고 시점을 명시한다.
