# 4.4 도메인 Rubric

## 1단계 논문 사실

다음 다섯 항목의 RAG 추출 결과를 평가 입력으로 사용한다.

1. KV cache 메모리 절감률과 성립 조건
2. 재학습·튜닝·보정 데이터 필요 여부
3. 추가 하드웨어·메모리 계층·대역폭 전제
4. 정확도 손실 수치와 실험 조건
5. 전송·프리패치·추가 연산 오버헤드

검색 결과가 없으면 `논문에 근거 없음`을 그대로 유지한다.

## 2단계 배포 제약 판정

- `적합`: 재학습·보정 데이터가 필요하지 않고, 대상 기기에 없는 자원을
  전제하지 않음
- `조건부`: 한 조건을 충족하지 못하지만 기기의 대응 자원으로 우회할 가능성이 있음
- `부적합`: 대상 기기에 없는 자원을 전제하고 확인된 대응 방법이 없음

정확도 손실과 오버헤드는 판정 조건이 아니다. 각각 Recall과 Latency 축에
기록하고, 메모리 효과는 Memory 축에 기록한다.

출력은 `verdict`, `rationale`, `positives`, `negatives`,
`axes{recall, latency, memory}`, `evidence`, `confidence`를 포함한다.
