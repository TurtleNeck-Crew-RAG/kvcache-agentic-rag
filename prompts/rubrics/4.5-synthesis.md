# 4.5 종합 Rubric

매트릭스의 행은 `기술 성숙도`, `시장`, `이해관계자`, `도메인`으로 고정한다.
각 행에서 KIVI와 InfiniGen을 나란히 요약하되, 점수 합산이나 순위를 만들지 않는다.

`agreements`는 다음을 기록한다.

- 두 개 이상의 관점이 같은 사실을 같은 방향으로 해석한 경우
- 두 기술에 공통으로 확인된 적용 조건 또는 한계

`conflicts`는 다음 중 하나 이상을 구체적으로 기록한다.

- 같은 기술을 관점별로 다르게 판정한 경우
- 동일한 사실을 관점마다 다르게 해석한 경우
- 하나의 관점 안에서 긍정·부정 근거의 강도가 비슷한 경우

각 문장은 입력에 있는 `[논문 p.N]`, `[웹 URL]`, `[추론]` 태그를 가능한 한 유지한다.
출처가 없는 판단을 새 사실처럼 쓰지 않는다. 특정 기술을 추천하거나 우열을 단정하지 않는다.
